# GitHub Pages Deployment

This directory contains the built frontend files for GitHub Pages deployment.

## Deployment Process

1. Make changes to the frontend code
2. Run the deployment command from the root directory:
   ```bash
   npm run deploy
   ```
3. Commit and push the changes to your repository
4. GitHub Pages will automatically serve the updated site

## Files

- `.nojekyll` - Prevents Jekyll processing
- `404.html` - Handles client-side routing for single-page applications
- All other files are generated by the Vite build process

## Important Notes

- This directory is automatically generated and should not be edited manually
- The deployment command builds the frontend and copies files here automatically
- Make sure your GitHub repository is configured to serve from the `/docs` folder on your main branch
